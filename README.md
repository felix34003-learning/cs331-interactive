# CS331 visual study library

Interactive algorithm and concept lessons powered by ManimGX.

Open https://felix34003-learning.github.io/cs331-interactive/ in Chrome or Edge with WebGPU. Use topic navigation, search, first/second-half filters, exam grouping, and step controls. First load downloads the browser Python runtime; no MP4 files are stored. The question button copies exact diagram context for a separate Codex chat. It does not send a message automatically.

Scope is based on the current course slides and the Midterm 1/2 Canvas announcements. Course orientation is separate from exam scope. The original Canvas slides, notebooks, and assignments are not included.
